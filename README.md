# 我的 AI 工作流资料

日更自媒体的全套 AI 工作流 Skill 与配置记录。基于 Claude Code（DeepSeek API）运行。

## 工作流总览

```
日报 SKILL（三线）──→ 纵横分析 SKILL ──→ 作者本人写稿 ──→ 文章到视频工作流 SKILL
  新闻素材               写作素材包           │
                            │                └─ 发布公众号 + 各视频平台
                      发现知识缺口 ──→ 跨学科深度研究 SKILL
                                      （快速查证 / 深度研究）
```

**核心原则：AI 只出素材 + 基本逻辑，不写稿、不下判断。判断、角度、成稿均由作者本人完成。**

## 典型使用顺序

1. 跑对应日报 Skill，拿到当日新闻素材
2. 对感兴趣的条目说"展开分析/深挖一下" → 纵横分析出写作素材包
3. 素材包中标注 [待核实] 或知识缺口 → 跨学科深度研究补查
4. 作者本人写稿（AI 不介入）
5. 公众号排版发布 → 文章转视频工作流出片发布

## 安全底线

- API Key 等凭证绝不粘贴给大模型
- 第三方 Skill 使用前先让 AI 审查，永不开启自动更新
