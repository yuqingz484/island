# 青萍和岛 · AI 写作工作流

**一个基于 Claude Code 的时政与气候分析自媒体全栈工作流。**

从信息抓取、纵横分析、跨学科研究，到风格成稿、视频发布的完整链路。7 个 SKILL 协同工作，覆盖写作全生命周期。

## 设计哲学

**日报驱动，不是灵感驱动。** 每天跑日报 → 从新闻中筛选选题 → 纵横分析深挖 → 成稿。不靠"今天想到什么写什么"。

**信源可追溯。** 每条新闻必须标注信源 URL。科学数据必标观测机构和基准期。政策引用必标发文机关和生效时间。不确定的事实标注 `[待核实]`。

**方法可复用。** 纵横分析框架、绿色溢价、跨学科概念迁移——不依赖单次灵感的写作系统。

**写作不是研究。** 研究是"搞清楚"，写作是"讲清楚"。跨学科研究提供底气，风格 SKILL 负责把复杂逻辑转化为读者看得懂的判断。

## SKILL 详解

### 日报层

#### 1. 国际政治与军事日报

```
触发：国际局势、大国关系、军事冲突、地区安全、外交动态
搜索：5 路并行（大国博弈 / 地区冲突 / 军事安全 / 多边机制 / 外交）
输出：结构化日报，含今日焦点、大国关系、地区冲突、军事安全、多边机制与外交
信源：Reuters, AP, AFP, 新华社 + 官方声明 + 权威媒体
```

#### 2. 国际经济与金融日报

```
触发：贸易战、经济制裁、能源地缘、供应链重构、去美元化、主权债务
搜索：5 路并行（制裁贸易 / 能源资源 / 供应链产业 / 金融货币 / 多边机制）
输出：制裁与贸易、能源与资源、供应链与产业、金融与货币
信源：各国央行/IMF/World Bank + FT/Bloomberg/WSJ + 专业智库
```

#### 3. 国内外气候与环境日报

```
触发：气候变化数据、极端天气、碳市场、能源转型、气候外交、生态环境
搜索：5 路并行（气候科学 / 能源转型 / 碳市场 / 气候治理 / 生态适应）
输出：气候变化与极端天气、能源转型与碳排、碳市场与气候金融、国际治理与生态
信源：IPCC/WMO/IEA/CMA + Nature/Science + Carbon Brief/WRI
强制规则：温度数据必标基准期，归因表述必标归因研究来源
```

### 分析层

#### 4. 纵横分析 SKILL

三线日报的统一分析框架。核心动作：

| 步骤 | 内容 |
|------|------|
| **选题筛选** | 日报头条 2-3 条 → 5 条"值得写的信号"筛查 → 选题量级判断（日常深度档 / 宏观大判断档） |
| **纵轴** | 因果链追溯：直接触发 → 结构性背景 → 关键转折点。不做流水账，只保留最近的因果节点 |
| **横轴** | 利益相关方图谱："公开说""实际做""真实诉求"三层对照 + 外溢效应 + 叙事竞争 |
| **交汇** | 纵轴逻辑 + 横轴格局 = 新判断。给出具体后续观察指标 |

**三线适配：**

| 线路 | 日报来源 | 横轴核心 |
|------|---------|---------|
| 线路一 | 国际政治与军事 | 利益相关方图谱 |
| 线路二 | 国际经济与金融 | 市场参与者 + 产业链传导 |
| 线路三 | 国内外气候与环境 | 气候系统各圈层 + 利益相关方 + 政策博弈 |

**地缘政治与历史分析增强层**（宏观大判断档启用）：资源竞争追问 → 忠/患结构判定 → 2.5 黄金分割边界检查 → 千年周期定位 → 赢家输家清单 → 剧本分叉。

#### 5. 跨学科深度研究 SKILL

在纵横分析遇到知识缺口时介入。

| 模式 | 耗时 | 适用场景 |
|------|------|---------|
| **快速查证** | 30 分钟 | 具体事实/数据/机制/条款的核实 |
| **历史对位验证** | 15 分钟 | 宏观大判断档的历史类比可靠性检验 |
| **深度研究** | 半天-一天 | 为大选题建立跨学科知识基底 |

核心工具：
- **信源白名单 & 黑名单**：强制信源质量管控
- **双轨验证**：同一事实至少 2 个独立信源确认
- **概念迁移表**：博弈论、系统论、金融学、生态学、气候学等 15+ 学科的概念工具
- **历史对位案例库**：17 个已验证的历史参照及其关键差异

### 写作层

#### 6. 青萍和岛个人风格 SKILL

学者型自媒体的写作风格规范。

| 要素 | 规范 |
|------|------|
| **标题** | 判断型命题句，15-25 字，不用"浅析""刍议" |
| **开篇** | 核心判断开门 / 概念锚定 / 自问自答。禁用"在当今…的时代" |
| **段落** | 1-3 句为主，关键判断独立成段。长短句交替 |
| **口语判断** | 在事实后给出锋利判断。密度：3000 字约 3-5 处 |
| **收尾** | 提炼底层逻辑，不回环，不升华 |
| **比喻** | 一个就够。日常可见，不需要解释 |

**绝对禁区**：禁用"首先其次最后""综上所述""赋能""抓手""闭环""本质上"。禁用感叹号连用。禁用标题党。

**事实核查（强制）**：每个新闻事实回原始信源逐字核对。外文机构首次出现注中文全称。

### 发布层

#### 7. 公众号到视频号工作流 SKILL

五阶段全流程：

```
AI 生成口播稿（600-750 字，口语化）
    → 手机剪映提词器录制（竖屏，翻领正装+胡萝卜夹子）
        → 剪映云空间同步
            → 电脑剪映专业版精剪（字幕宋体简13号+降噪+少年光感+配乐-8dB）
                → 视频号助手 + 可画封面 → 发布
```

## 数据质量标准（全链路通用）

### 信源优先级

| 等级 | 信源类型 | 示例 |
|------|---------|------|
| Tier 1 | 官方一手信源 | 政府公报/部委官网/国际组织报告/权威机构数据集 |
| Tier 2 | 权威学术/研究 | 同行评审期刊/大学出版社专著/顶级智库报告 |
| Tier 3 | 权威媒体 | Reuters/AP/AFP/新华社/BBC/FT/Economist |
| Tier 4 | 行业数据/分析师 | 行业报告/券商研报/专业数据平台 |
| Tier 5 | 其他 | 仅交叉验证，不作主信源 |

### 交叉验证规则

- 3+ 独立信源 → "已确认"
- 1-2 信源 → 标注"待核实"
- 单一信源且来自 Tier 5 → 不收录
- 政策类强制双验证：至少 1 个官方信源确认

### 信源黑名单

百度百科 / 知乎 / 今日头条 / 抖音 / 微博非蓝V / 百度文库 / 道客巴巴 / CSDN 博客 / 雪球非认证用户

## 使用示例

### 日常写作流程

```
1. 用户：跑一下今天的国际政治日报
   → 国际政治与军事日报 SKILL 输出 10+ 条新闻

2. 用户：对第 3 条展开纵横分析  
   → 纵横分析 SKILL 判断选题价值 → 展开纵轴/横轴/交汇 → 输出结构稿

3. （如遇知识缺口）
   → 跨学科深度研究 SKILL 快速查证模式 → 补齐关键事实

4. 用户：转成青萍和岛风格成稿
   → 青萍和岛风格 SKILL 处理语言 → 成品稿

5. 用户：这篇文章做视频
   → 公众号到视频号工作流 SKILL → 口播稿 → 录制 → 精剪 → 发布
```

### 气候选题工作流

```
1. 用户：跑一下今天的气候与环境日报
   → 国内外气候与环境日报 SKILL 输出气候科学+政策+市场简报

2. 用户：这条"海洋热含量创新高"做宏观大判断
   → 纵横分析 SKILL 线路三（气候与环境）→ 超长因果链+数据锚点+剧本分叉

3. （需要历史参照）
   → 跨学科研究 SKILL 历史对位验证（如"明末小冰期 vs 当代全球变暖"）
   → 强制标注关键差异（"古代无工业化农业体系抗灾力弱"）

4. → 青萍和岛风格成稿
```

## 安装与使用

本项目为 [Claude Code](https://claude.ai/code) SKILL 文件集合。每个 SKILL 是一个独立的 Markdown 文件。

### 方式一：手动调用

将 `SKILL.md` 文件放置在工作目录中，在 Claude Code 会话中通过 Skill 工具调用。

### 方式二：作为提示词模板

每个 SKILL 文件本身就是完整的方法论文档，可将其内容作为提示词复制到任何支持系统提示词的 AI 工具中。

### 前置要求

- 日报类 SKILL 依赖 Claude Code 内置的 `WebSearch` 和 `WebFetch` 工具
- 分析类/写作类 SKILL 无外部依赖，纯方法论框架
- 视频工作流 SKILL 依赖剪映 App + 剪映专业版 + 可画（Canva）

## 设计原则

1. **模块化**：每个 SKILL 独立可用，也可串联为完整工作流
2. **可演进**：每个 SKILL 末尾附"持续改进"规则，基于实际使用反馈迭代
3. **零外部依赖**（分析/写作层）：日报层仅需 WebSearch+WebFetch（Claude Code 内置）
4. **硬约束明确**：信源黑名单、强制双验证、不准编造——用规则代替自律
5. **研究写作分离**：研究产出是底气，不是直接贴到稿件里的素材
