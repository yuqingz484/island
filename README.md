# 青萍和岛 · AI 内容工作流

基于 Claude Code + DeepSeek API 的自媒体内容生产系统，覆盖从**选题发现 → 深度分析 → 成稿 → 视频化**的全流程。

## 工作流概览

```
三线日报 SKILL（每日自动抓取新闻）
       │
       ▼
纵横分析 SKILL（选题筛选 + 深度分析框架）
       │
       ├── 跨学科深度研究 SKILL（知识缺口补齐 + 信源验证）
       │
       ▼
青萍和岛风格 SKILL（按个人风格成稿）
       │
       ├──→ 公众号发布
       └──→ 视频号工作流（口播稿 → 提词器录制 → 剪映精剪 → 发布）
```

### 三线日报

每天自动抓取三个维度的新闻简报：

| 线路 | 覆盖范围 |
|------|---------|
| 国际政治与军事 | 大国关系、地区冲突、军事动态、多边机制、外交事件 |
| 国际经济与金融 | 制裁与关税、能源地缘、供应链重构、金融货币体系 |
| 国内产业与政策 | 部委政策发文、产业动态、财税监管、区域规划 |

### 纵横分析

基于横纵分析法（Horizontal-Vertical Analysis），对选题做两件事：
- **纵轴**：追溯因果链，回答"怎么走到这一步的"
- **横轴**：展开博弈图谱，拆解各方"公开说的 / 实际做的 / 真正想要的"

分日常深度（1500-3000 字）和宏观大判断（3000-6000 字）两档。

### 写作风格

公众号"青萍和岛"覆盖两类文章：
- **个人随笔**（1000-2000 字）：从真实体验出发，引出成长感悟
- **国际时政长文**（3000-5000 字）：基于新闻数据拆解多方博弈逻辑

风格关键词：内省克制、逻辑清晰、敢下判断、口语化但不油腻。

### 视频化

从公众号文章到视频号成品，五阶段流水线：AI 口播稿 → 手机剪映提词器录制 → 云空间同步 → 电脑剪映专业版精剪 → 视频号助手发布。

## 技术栈

- **AI 终端**：Claude Code（通过 DeepSeek Anthropic 兼容接口）
- **模型**：DeepSeek V4 Pro / Flash
- **运行环境**：macOS + Node.js 18+

## 快速开始

1. 按 `deepseek API配置全流程记录.md` 完成环境搭建
2. 将 SKILL 文件配置为 Claude Code Skills
3. 运行三线日报获取当日选题
4. 对感兴趣的新闻触发纵横分析 → 成稿
