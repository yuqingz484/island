# 青萍和岛 · AI 写作工作流

基于 Claude Code 的时政与气候分析自媒体全栈工作流。8 个 SKILL + 3 个配套文件。

## 工作流链路

```
日报层（信息输入）      分析层（深度加工）      写作层         发布层
────────────────────────────────────────────────────────────────────
国际政治与军事日报 ─┐
国际经济与金融日报 ─┤
国内外气候与环境日报 ─┼──→ 纵横分析 ──→ 青萍和岛风格 ──→ 文章到视频
国内外未来产业日报 ─┘         │
                         跨学科深度研究（遇知识缺口时介入）
```

## 文件清单

### 日报层
| 文件 | 用途 |
|------|------|
| `国际政治与军事日报SKILL.md` | 大国博弈、地区冲突、军事安全、多边机制、外交动态 |
| `国际经济与金融日报SKILL.md` | 制裁贸易、能源资源、供应链、金融货币、资本市场 |
| `国内外气候与环境日报SKILL.md` | 气候科学、能源转型、碳市场、气候治理、生态适应 |
| `国内外未来产业日报SKILL.md` | 量子科技、生物制造、核聚变、脑机接口、具身智能、6G |

### 分析层
| 文件 | 用途 |
|------|------|
| `纵横分析SKILL.md` | 选题筛选 → 纵轴因果追溯 → 横轴博弈图谱 → 交汇判断。分日常深度档和宏观大判断档 |
| `跨学科深度研究SKILL.md` | 快速查证(30min) / 历史对位验证(15min) / 技术原理查证(20min) / 深度研究(半天+) |

### 写作层
| 文件 | 用途 |
|------|------|
| `青萍和岛个人风格SKILL.md` | 标题、开篇、段落节奏、口语判断、收尾的风格规范与禁区 |

### 发布层
| 文件 | 用途 |
|------|------|
| `文章到视频工作流SKILL.md` | 口播稿 → 手机录制 → 云同步 → 电脑精剪 → 发布 |

### 配套文件
| 文件 | 用途 |
|------|------|
| `跨学科深度研究_引用库.md` | 历史对位案例库、概念迁移表、权威信源书目 |
| `ai介入工作保密风控要点.md` | API Key 安全、Skills 供应链攻击防范 |
| `deepseek API配置全流程记录.md` | Mac 环境 DeepSeek API 接入 Claude Code 配置指南 |

## 使用方式

每个 SKILL 文件即完整的方法论文档。在 Claude Code 会话中通过 Skill 工具调用，或作为提示词复制到任意 AI 工具使用。日报类依赖 WebSearch + WebFetch（Claude Code 内置），其余无外部依赖。
