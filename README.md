# 青萍和岛 AI 工作流

> 一个独立学者型自媒体的 AI 写作管线——从三线日报选题、纵横分析、跨学科研究到风格成稿与视频分发，全套 Claude Code Skills。

## 这是什么

一套运行在 Claude Code 上的 **Skills 集合**，覆盖国际时政自媒体的完整内容生产流程。它不是在"帮你写稿"，而是在搭建一条管线：

```
三线日报 SKILL              纵横分析 SKILL           跨学科深度研究 SKILL      风格 SKILL          视频号工作流 SKILL
─────────────              ──────────────          ──────────────────     ────────────────    ──────────────────
国际政治与军事日报 ─┐                                               
国际经济与金融日报 ─┼──→  选题筛选 + 量级判断   →   不懂的部分查清楚   →   青萍和岛 / 洋恺   →   转成视频发出去
国内产业与政策日报 ─┘        │                       30 min / 半天          核心环节              20 min
                              │
                         ┌────┴────┐
                         ↓         ↓
                    日常深度档   宏观大判断档
                   （1500-3000字）（3000-6000字）
                    青萍和岛风格   洋恺五幕剧风格
```

每条 Skill 是独立的，但按设计顺序串联时，构成一个完整流水线。你可以在任意节点切入——比如手头已有选题，直接从纵横分析开始。

| Skill | 解决的问题 | 时长 |

## 设计理念

### 研究与写作分离

每个 Skill 都有一条清晰的边界——研究就是研究，写作就是写作。跨学科研究 Skill 的产出是"你作为作者的底气"，不是直接贴到稿子里的素材。纵横分析提供的是结构框架，风格层负责把框架变成"这个人在说话"。

### 日更友好

整个管线为**日更节奏**设计，不是为万字报告或学术论文。每个环节都做了深浅两档：快速查证模式 30 分钟补齐知识缺口，深度研究模式半天建立跨学科基底。选题筛选有明确的"不值得写的信号"——帮你拒绝掉 80% 的新闻。

### 双档深度

纵横分析 SKILL 内置**两档分析深度**，选题阶段自动判断量级：

- **日常深度档**：3-5 年因果链追溯 + 标准利益方图谱，对接青萍和岛风格
- **宏观大判断档**：千年尺度历史对位 + 赢家/输家清单 + 数据锚点 + 剧本分叉，对接洋恺五幕剧风格

宏观大判断档自动触发跨学科深度研究的"历史对位验证"专项，确保历史案例使用的是史学界共识版本而非演义版本。

### 信源铁律

完整的信源白名单/黑名单和交叉验证规则。核心原则：能用一手官方文件和权威通讯社的，不引用二手解读；所有中文网络百科、内容聚合平台、自媒体黑名单一律禁用。中东问题必须加入波斯语料对比，中文数据必须经国际权威源交叉验证。历史对位引用须通过史学界共识验证。

### 你才是作者

整条管线做的事情：把机械劳动交给 AI，把判断留给作者。日报帮你扫描信息，纵横分析帮你搭结构，跨学科研究帮你查资料——但选题选哪条、观点怎么定、用日常档还是宏观档、风格怎么打磨，都是你的事。最终成稿里的"我"，必须是真实的你。

## 快速开始

### 前置条件

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 已安装
- API Key（Anthropic 官方或 DeepSeek 兼容接口均可）

如果使用 DeepSeek API，参考 [`deepseek API配置全流程记录.md`](deepseek%20API配置全流程记录.md) 进行配置。

AI 介入写作的安全注意事项见 [`ai介入工作保密风控要点.md`](ai介入工作保密风控要点.md)。

### 安装 Skill

将这些 `.md` 文件放入项目目录，Claude Code 会自动识别为可用 Skill。在对话中使用自然语言即可触发：

```
# 生成三线日报
"今天国际有什么大事"              → 国际政治与军事日报
"今天全球经济有什么动态"          → 国际经济与金融日报
"今天国内有什么产业政策"          → 国内产业与政策日报

# 选题与分析
"这条展开分析一下"               → 纵横分析（自动判断日常档/宏观档）
"帮我做纵横分析"                 → 同上
"这个选题大，用宏观档写"         → 强制使用宏观大判断档

# 研究查证
"这个历史类比可靠吗"             → 历史对位验证（跨学科深度研究）
"这个机制我不太懂，查一下"       → 快速查证模式

# 写作
"写随笔"                        → 青萍和岛风格
"写成洋恺风格的宏观分析"         → 洋恺五幕剧风格

# 分发
"把这篇文章转成口播稿"           → 公众号到视频号工作流
```

### 推荐的日更节奏

1. **早上**：跑三线日报，6 分钟扫一遍今天的国际政治、国际经济、国内产业热点
2. **选题**：纵横分析自动扫描日报头条 2-3 条，输出选题判断卡 + 量级判断
3. **写稿**：纵横分析搭框架 → 遇到不懂的调用跨学科研究 → 风格化成稿
4. **有空时**：做深度研究基底，为反复出现的大选题建立跨学科知识储备
5. **文章火了/想扩大传播**：跑视频号工作流，20 分钟转成口播视频

## 适用范围

**适合**：独立创作者、小型媒体团队、需要日更国际时政内容的写作者

**不适合**：纯营销号（风格层强调信息增量和判断力，不整标题党那套）、学术写作（框架为 1500-6000 字自媒体稿设计，不是论文）、国内社会新闻（日报层聚焦国际与产业维度）
