# 青萍和岛 AI 工作流

> 一个独立学者型自媒体的 AI 写作管线——从选题发现、跨学科研究、深度分析到视频分发，全套 Claude Code Skills。

## 这是什么

一套运行在 Claude Code 上的 **Skills 集合**，覆盖国际时政自媒体的完整内容生产流程。它不是在"帮你写稿"，而是在搭建一条管线：**日报跑选题 → 纵横分析定框架 → 跨学科研究补缺口 → 风格化写作成稿 → 稿转视频分发**。

每条 Skill 是独立的，但按设计顺序串联时，构成一个完整流水线。你可以在任意节点切入——比如手头已有选题，直接从纵横分析开始。

```
日报 SKILL         纵横分析法 SKILL      跨学科深度研究 SKILL    青萍和岛风格 SKILL   视频号工作流 SKILL
─────────         ──────────────       ──────────────────     ────────────────    ────────────────
今天发生什么   →   哪条值得写？     →   不懂的部分查清楚   →   写成"这个人"的话  →   转成视频发出去
2 min              30 sec              30 min / 半天             核心环节              20 min
```

## Skills 总览

| Skill | 解决的问题 | 时长 |
|-------|-----------|------|
| [国际时政日报](国际时政日报SKILL.md) | 今天国际上有哪些值得关注的事？ | ~2 min |
| [纵横分析法](国际时政纵横分析法SKILL.md) | 10+ 条新闻里，哪条值得写成深度稿？怎么写？ | 选题 30s + 分析 5-8 min |
| [跨学科深度研究](跨学科深度研究SKILL.md) | 写稿时遇到不懂的领域，怎么系统性地查？ | 快速 30 min / 深度半天 |
| [青萍和岛风格](青萍和岛个人风格SKILL.md) | 把分析变成"这个人"在说话，而非 AI 在写稿 | 核心环节 |
| [视频号工作流](公众号到视频号工作流SKILL.md) | 文章怎么变成 3 分钟口播视频？ | ~20 min |

## 设计理念

### 研究与写作分离

每个 Skill 都有一条清晰的边界——研究就是研究，写作就是写作。跨学科研究 Skill 的产出是"你作为作者的底气"，不是直接贴到稿子里的素材。纵横分析法提供的是结构框架，青萍和岛风格 Skill 负责把框架变成"这个人在说话"。

### 日更友好

整个管线为**日更节奏**设计，不是为万字报告或学术论文。每个环节都做了深浅两档：快速模式 30 分钟补齐知识缺口，深度模式半天建立跨学科基底。选题筛选有明确的"不值得写的信号"——帮你拒绝掉 80% 的新闻。

### 信源铁律

继承了一套完整的信源白名单/黑名单和交叉验证规则。核心原则：能用一手官方文件和权威通讯社的，不引用二手解读；所有中文网络百科、内容聚合平台、自媒体黑名单一律禁用。中东问题必须加入波斯语料对比，中文数据必须经国际权威源交叉验证。

### 你才是作者

整条管线做的事情：把机械劳动交给 AI，把判断留给作者。日报帮你扫描信息，纵横分析帮你搭结构，跨学科研究帮你查资料——但选题选哪条、观点怎么定、风格怎么打磨，都是你的事。最终成稿里的"我"，必须是真实的你。

## 快速开始

### 前置条件

- [Claude Code](https://docs.anthropic.com/en/docs/claude-code) 已安装
- API Key（Anthropic 官方或 DeepSeek 兼容接口均可）

如果使用 DeepSeek API，参考 [`deepseek API配置全流程记录.md`](deepseek%20API配置全流程记录.md) 进行配置。

### 安装 Skill

将这些 `.md` 文件放入项目目录，Claude Code 会自动识别为可用 Skill。在对话中使用自然语言即可触发：

```
# 生成今日国际时政日报
"今天国际有什么大事"

# 对日报中的某条新闻展开分析
"这条展开分析一下"

# 写一篇纵横分析稿
"帮我做纵横分析"

# 写随笔
"写随笔"

# 把文章转成视频口播稿
"把这篇文章转成口播稿"
```

### 推荐的日更节奏

1. **早上**：跑日报 Skill，2 分钟扫一遍今天的热点
2. **选一条**：纵横分析法自动判断哪条值得写，输出选题判断卡
3. **写稿**：纵横分析搭框架 → 遇到不懂的调用跨学科研究 → 风格 Skill 成稿
4. **有空时**：做深度研究基底，为反复出现的大选题建立知识储备
5. **文章火了/想扩大传播**：跑视频号工作流，20 分钟转成口播视频

## 适用范围

**适合**：独立创作者、小型媒体团队、需要日更国际时政内容的写作者

**不适合**：纯营销号（风格 Skill 强调信息增量和判断力，不整标题党那套）、学术写作（框架为 1500-5000 字自媒体稿设计，不是论文）、国内社会新闻（日报 Skill 聚焦国际维度）
